# Patriot web-to-print demo

Static demo site for demow2p.patriotpf.com. No build step.

- `index.html` demo home
- `order.html` ordering app and back office (interactive)
- `wholesale.html`, `catalog.html` printsbypatriot.com mockups
- `retail.html`, `yard-signs.html` patriotpf.com mockups
- `img/` product photos

Pages are marked noindex. Nothing here places real orders or charges cards.

Deploy: Cloudflare Pages, connected to this repo, build command empty, output directory `/`.
